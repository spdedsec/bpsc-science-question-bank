## Pedagogical Rationale — The 0% MCQ Methodology

### Why Abandon Multiple-Choice Format for Science Preparation?
In recent BPSC Prelims cycles, the Commission overhauled the examination pattern:
- **Negative Marking (0.33 mark penalty)** penalizes speculative guessing.
- **Ambiguous Distractors** in 4-choice/5-choice stems induce cognitive interference and confirmation bias during revision.
- Aspirants frequently memorize incorrect options or waste critical preparation hours deciphering synthetic distractors rather than absorbing invariant scientific principles.

### The Direct Q&A Advantage:
```
Traditional MCQ Guide (Flawed)         This Monograph: Direct Q&A (High Yield)
┌─────────────────────────────────┐    ┌──────────────────────────────────────────────┐
│ Q: Which instrument measures...?│    │ Q: Which scientific instrument measures     │
│  (A) Barometer   (B) Bolometer  │ ──►│    thermal radiation intensity?              │
│  (C) Pyrheliometer (D) Hydrometer│    │ A: Pyrheliometer (पाइरहेलियोमीटर).            │
│  (E) None of the above          │    │    [Explanation & Devanagari Translation]   │
└─────────────────────────────────┘    └──────────────────────────────────────────────┘
   Cognitive clutter & guesswork             Active recall & immediate truth encoding
```

- **Cognitive Priming**: Direct Q&A encodes the ground truth into long-term semantic memory.
- **Speed of Revision**: Candidates can review 100+ concepts per hour without wading through 400 irrelevant distractor clauses.
- **Dual utility for Prelims & Mains**: Deep conceptual explanations build a strong foundation for BPSC General Studies Paper II (Science & Technology section).

## Data Schema & Contracts

Every entry in `data/*.json` strictly satisfies the following canonical schema:

```json
{
  "id": "PHY-MEC-001",
  "subject": "Physics",
  "topic": "Mechanics, Gravitation & Fluid Dynamics",
  "subtopic": "Centripetal Force & Curvature Motion",
  "exam_reference": "66th BPSC CCE Prelims (Re-Exam) / Syllabus Adjacent",
  "english": {
    "question": "What is the primary physical function of centripetal force acting on an object?",
    "answer": "It continuously redirects the velocity vector of the object toward the center of curvature, maintaining its motion along a curved or circular path without altering its linear speed."
  },
  "hindi": {
    "question": "किसी वस्तु पर कार्य करने वाले अभिकेंद्रीय बल (Centripetal Force) का मुख्य भौतिक कार्य क्या है?",
    "answer": "यह वस्तु के वेग सदिश (velocity vector) को वक्रता केंद्र की ओर निरंतर निर्देशित करता है, जिससे वस्तु अपनी रैखिक चाल बदले बिना वृत्ताकार या वक्र पथ पर गतिशील बनी रहती है।"
  }
}
```

### Strict Content Rules Enforced in CI/CD:
- **Identifier Syntax**: Regex `^[A-Z]{3}-[A-Z0-9]{3,4}-[0-9]{3,4}$`.
- **Subject Classification**: Exactly one of `["Physics", "Chemistry", "Biology", "Bihar Science & Environment"]`.
- **Punctuation**: English question ends with `?`; Hindi question ends with `?` or `।`.
- **Bilingual Completeness**: 100% paired; no empty strings or whitespace.
- **Zero-MCQ Enforcement**: Absolute rejection of `(A)`, `(B)`, `(C)`, `(D)`, `(E)`, `[A]`, `Option A`, `None of the above`, `More than one of the above`, `Which of the following`, `निम्नलिखित में से`.

## How to Build the Book from Source

### Prerequisites
1. **Python 3.10+** (Python 3.14 tested)
2. **Typst 0.15.1+** (Fast, modern document compiler)
3. **Fonts**:
   - `Liberation Sans` (Latin headings and body)
   - `Noto Sans Devanagari` (Full Unicode Hindi Devanagari glyphs)

*On Arch Linux / Omarchy:*
```bash
sudo pacman -S typst ttf-liberation noto-fonts
```

*On Debian / Ubuntu:*
```bash
sudo apt-get install typst fonts-liberation fonts-noto-core
```

### One-Command Compilation
To regenerate `bpsc_science_question_bank.typ` and compile `bpsc_science_question_bank.pdf`:
```bash
python3 scripts/build_book.py
```

The script automatically:
1. Loads and validates all 812 questions from `data/*.json`.
2. Assembles front matter, blueprint tables, subject chapters, bilingual blocks, and appendices.
3. Generates the Typst document `bpsc_science_question_bank.typ`.
4. Invokes `typst compile` to produce the 353-page publication-ready PDF in 6" × 9" US Trade format.
